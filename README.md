# 자기 진화형 Medical AI Agent — 로드쇼 체험 (태블릿)

## 구성
- `index.html` — 부스 허브. 체험 1 / 체험 2 선택, 전체화면 버튼
- `demo1/` — 체험 1 · 먼저 짚는다: 환자 한 명의 진료 기록 (실제 사례를 재구성한 환자 6명 = MIMIC A·B·C + OMOP D·E·F, 예측 걸기, 시간 비교, 학습 게이트)
- `demo2/` — 체험 2 · 의사의 판단을 돕다: 가상의 나를 만들고 에이전트와 검사 고르기 대결 (실시간 확률, 판단 근거 비교, 리포트 카드)
- `shared.css` / `shared.js` — 공용 디자인 시스템과 런타임(라우터, 타이핑, 확률 벽, 도장, 방치 복귀, 부스 통계)
- `demo_data.js` — 체험 1 의 MIMIC 축 케이스 A·B·C  ·  `engine.js` — 체험 2 대리 모델  ·  `logos.js` — 로고
- `omop_data.js` — 체험 1 의 OMOP 축 케이스 D·E·F. `demo_data.js`와 같은 스키마

## 실행
`index.html`을 태블릿 브라우저로 열면 됩니다(서버 불필요). iPad는 Safari "홈 화면에 추가" 후 실행하면 주소창이 사라집니다. `f` 키 또는 허브의 전체화면 버튼.

## 부스 기능
- 90초 동안 조작이 없으면 "계속 보기" 안내 후 15초 뒤 처음 화면으로 자동 복귀
- 방문자 수, 검사 고르기 대결 결과가 기기의 localStorage에 누적되어 첫 화면에 표시 (개인 정보 없음)
- 모든 애니메이션은 "바로 완료" 버튼과 → 키로 건너뛸 수 있음

## 체험 1 의 환자 6명

| | 소스 | 진료 환경 | 타임라인 초점 | 관찰창 |
|---|---|---|---|---|
| A | 작성 케이스 | 응급실 | 당뇨 | 도착 48분 · 6건 |
| B | 작성 케이스 | 응급실 | 패혈증 | 도착 26분 · 13건 |
| C | **MIMIC-IV** subject 12094729 | 응급실 | 전해질 이상 | 도착 15분 · 12건 |
| D | **OMOP** patient_index 14904 | 안과 → 내과 | 당뇨 | 첫 방문 52분 · 9건 |
| E | **OMOP** patient_index 6948 | 건강검진 외래 | 지질대사 장애 | 첫 방문 48분 · 11건 |
| F | **OMOP** patient_index 14933 | 피부과 외래 | 고혈압 | 첫 방문 32분 · 10건 |

### OMOP 축 (D·E·F)
생성환자 데이터(`generated_060641`, 앞 20,000명)에서 **당뇨 + 고혈압 + 이상지질 진단코드를 모두 가진 261명**을 추린 뒤 방문 수·약물 3계열·앵커 이후 발생 여부로 정렬해 골랐다. 방문 분할·간격·각 방문의 concept_id와 개념명은 실제 데이터(`OMOP_SOURCE` 블록)이고, **성별·나이·수치·확률·판정 문장은 작성분**이다 — 생성 데이터의 값 열이 토큰과 정렬되지 않아 수치 복원이 불가하다(`omop_data/patient_loader.py`의 value 정렬 주석 참고).

### MIMIC 축 (C)
`Agent/multi_skill/rank_head/cohorts/` 의 관찰창·이후 기록·퇴원 진단 세트에서 골랐다. 25개 CCS 라벨 중 데모 DX25 로 대응되는 17개만 쓰는 조건으로 3,663명이 남았고, 그중 관찰창에 이상치가 뚜렷하고 이후 기록이 충분한 환자를 선정했다. **수치·정상범위·이상 플래그·이벤트 시각이 모두 실제 값**이다.

`demo1/index.html`에 이미 연결되어 있어(`patients = PATIENTS.concat(OMOP_PATIENTS)`) 환자 선택 화면에 A~F 6명이 함께 뜬다. 한쪽 축만 보여주려면 그 줄을 `let patients = OMOP_PATIENTS;`(또는 `PATIENTS`)로 바꾸거나 실행 중에 `loadPatients(...)`를 호출하면 된다.

## 서버 연결
- 체험 1: `demo_data.js`의 `PATIENTS` 교체 또는 `window.loadPatients(json)`
- 체험 2: `Engine.probs()`, `Engine.tree()` 반환 스키마만 맞추면 FM·LLM API로 교체 가능

## 로고
PPT에서 추출한 저해상도 버전입니다. `logos.js`의 base64를 고해상도 PNG/SVG로 바꾸면 헤더와 워터마크에 함께 반영됩니다.
